# Initialization

Tasks:

1. Identify the requested review target.
2. Inspect the target sufficiently to understand its purpose, structure, and primary technologies.
3. Create a `Context.md`. 

Output: `Context.md`

## Example `Context.md`

```text
# Code Review Context

## Target
Path: <target path>

## Project Overview
<Description based on inspected project files>

## Technologies
- <Language>
- <Framework>
- <Build system>

## Workflow Status

- Phase 1: Completed
- Phase 2: Incomplete
- Phase 3: Incomplete
- Phase 4: Incomplete

## Notes
<Relevant observations and limitations>
```
